## Candidate changes

`gap` now reads bounded keyset pages, using the existing contract cursor
format. `--limit` accepts 1..500, defaults to 50, and `--cursor` resumes after
the last ID. Counts describe the current page. Human output retains its
header and sends continuation to stderr; JSON retains its evidence fields
and adds `next_cursor` only when another page exists. The inferred tier,
current ruleset, declaration exclusions and empty-array output are preserved.
Regression tests cover output compatibility, 503-row traversal, terminal and
empty pages, invalid inputs, cancellation, environment overrides and failed
output writes. The HTTP API and database schema are unchanged.

The release security scan found GO-2026-6809 in Go 1.27.2. The active compiler,
CI pins and digest-pinned Docker build image now use Go 1.27.3. Its archive was
verified against the official checksum, and its Docker index digest was read
from the registry. The Go language floor remains 1.26; module versions and
`go.sum` did not change.
