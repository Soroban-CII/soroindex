# Demo script

Recorded on 9 October 2026 using the v0.1.0 candidate, a real 200-contract testnet index at ledger 5097816, and the recorded 7 October mainnet census. This is a local demonstration; no public API deployment is claimed. Absolute paths below identify the actual run. For a fresh recording, build with `scripts/build-release.sh`, seed your own testnet database as described in [Self-hosting](../self-hosting.md), and substitute its paths. Counts and contract history can change.

The operator waived Stage F step 28 because no deployed fixture was available. The history command therefore shows one real observed contract version, not an upgrade demonstration. No placeholder contract ID was used.
