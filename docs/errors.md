# CLI error catalog

Every `sep47idx` failure has a stable code. With `--json` the command writes
`{"error":{"code":"...","message":"..."}}` to stderr; without it, the same
message is printed as `sep47idx <command>: <message>`. Exit status is 0 on
success, 1 on error, and 2 when the requested object does not exist.

This page is generated by `scripts/gen-error-catalog.sh` from
`internal/clierr`; do not edit it by hand.

| Code | Exit | Sentinel | When |
| --- | ---: | --- | --- |
| `bad_request` | 1 | `store.ErrBadQuery` | A flag, pagination cursor, identifier or other query input is invalid. |
| `bad_request` | 1 | `store.ErrBadCheckpoint` | A stored ledger checkpoint is malformed. |
| `bad_request` | 1 | `config.ErrUnknownNetwork` | The --network value is not mainnet, testnet or futurenet. |
| `bad_request` | 1 | `match.ErrInvalidRules` | A rule file does not validate against rules/schema.json. |
| `bad_request` | 1 | `sepmeta.ErrNotWasm` | The input does not start with a Wasm v1 header. |
| `bad_request` | 1 | `sepmeta.ErrTruncated` | A Wasm section or XDR value ends before its declared length. |
| `bad_request` | 1 | `sepmeta.ErrMalformed` | A Wasm section is structurally invalid. |
| `bad_request` | 1 | `sepmeta.ErrLimit` | A configured Wasm or section size limit was exceeded. |
| `bad_request` | 1 | `ingest.ErrUnsupportedMeta` | A ledger metadata version is newer than this build understands. |
| `bad_request` | 1 | `ingest.ErrNotInstance` | A contract-data entry is not a contract instance. |
| `bad_request` | 1 | `ingest.ErrNotExecRef` | A contract-data entry is not a CAP-85 executable reference. |
| `bad_request` | 1 | `ingest.ErrMalformed` | A ledger entry or instance is structurally invalid. |
| `bad_request` | 1 | `ingest.ErrTooLarge` | An XDR value exceeds the configured decode limit. |
| `bad_request` | 1 | `ingest.ErrUnknownXDR` | Ledger metadata uses XDR this build cannot decode. |
| `bad_request` | 1 | `ingest.ErrLedgerGap` | A batch of ledgers is not consecutive. |
| `not_found` | 2 | `store.ErrNotFound` | The requested contract, Wasm, state key or page does not exist. |
| `not_matched` | 1 | — | `inspect --require-match` found the inferred interface status was not match. |
| `database_uninitialized` | 1 | `store.ErrReadOnlyUninitialized` | The database has no schema yet; run sync or seed it first. |
| `schema_too_new` | 1 | `store.ErrSchemaTooNew` | The database was migrated by a newer binary. |
| `schema_too_old` | 1 | `store.ErrSchemaTooOld` | The database predates this binary; run sync to migrate it. |
| `network_mismatch` | 1 | `store.ErrNetworkMismatch` | The database records a different network passphrase. |
| `database_locked` | 1 | `store.ErrWriterActive` | Another process holds the write lock; stop sync before maintenance. |
| `integrity_failed` | 1 | `store.ErrIntegrity` | SQLite's integrity check reported problems. |
| `retention_gap` | 1 | `sync.ErrRetentionGap` | The resume point is older than the RPC retention window; seed or backfill. |
| `network_reset` | 1 | `sync.ErrNetworkReset` | The network's history no longer matches this index; start a new database. |
| `not_implemented` | 1 | `claims.ErrNotImplemented` | A claim source exists but has no implementation. |
| `rpc_unavailable` | 1 | `rpc.ErrHTTP` | The RPC endpoint returned an HTTP error. |
| `rpc_unavailable` | 1 | `rpc.ErrResponseTooLarge` | An RPC response exceeded the configured size limit. |
| `rpc_unavailable` | 1 | `rpc.ErrProtocol` | The RPC response is not valid JSON-RPC 2.0 for the requested method. |
| `internal` | 1 | — | Any error without a more specific code. Report it with the command and ledger. |
