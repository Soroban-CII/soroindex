# Phase 0 report files

`ADOPTION.md` is generated by `sep47idx phase0` from the `*-summary.json`
files here; do not edit it by hand (`sep47idx phase0 --render-only` rebuilds it).

| File | What | In git |
| --- | --- | --- |
| `ADOPTION.md` | The adoption report (CLAUDE.md §5.10) | yes |
| `<network>-summary.json` | Every number in the report, machine-readable | yes |
| `<network>-raw.csv` | One row per Wasm hash: parse status, declared SEPs, anomalies, SEP-41 match | yes |
| `testnet-contracts.csv` | The testnet sample (one row per contract); usable as `sync --seed` | yes |
| `mainnet-contracts.csv` | The mainnet census population (21 MB) | no: regenerate |
| `mainnet_key_types.csv` | Hubble Q0 export (key types sanity check) | yes |
| `mainnet_hashes.csv` | Hubble Q1 export (every contract code hash) | yes |
| `mainnet_instances.csv` | Hubble Q2 export (every current instance, 93 MB) | no: regenerate |

## Regenerating

1. Run the queries in `scripts/hubble-export.sql` in BigQuery and save Q0–Q2 under
   the names above. Q2 exceeds the console's 10 MB local-download cap: save it
   with "CSV (Google Drive)", then check `wc -l` equals Q0's instance count + 1.
2. `sep47idx phase0 --network mainnet --rpc-url <url> --hashes report/mainnet_hashes.csv --instances report/mainnet_instances.csv --out report/`
3. `sep47idx phase0 --network testnet --sample 2000 --out report/`

The mainnet run of 2026-10-07 used `https://soroban-rpc.mainnet.stellar.gateway.fm`
(listed by Stellar's RPC provider docs; operator's choice of public endpoint).
